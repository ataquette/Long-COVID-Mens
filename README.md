# Long-COVID-Mens
Long COVID and menstruation: potential bidirectional associations and mechanisms by Maybin et al.
The paper is composed of 3 studies.
This folder contains the datasets and scripts to reproduce Studies 1 and 2.

# Study 1: Reported menstrual symptoms in a UK population of people who menstruate
The data are in the .Rda file, and is a list of 5 imputed datasets.
The script is a R markdown file . Rdm.
Running the script reproduces the descriptive Table 1, the DAG, the supplementary figure 1 (variants),  the main Figure 1 and all supplementary tables for model outputs.

# Study 2: Prospective study of long COVID symptoms across themenstrual cycle.
The data are in the .Rda file
The script is a R markdown file . Rdm.
Running the script reproduces Figure 3, Tables S7 and S8.
